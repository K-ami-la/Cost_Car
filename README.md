# 🚗 Coût réel d'une voiture

Quelle voiture coûte vraiment le moins cher ? Ce site compare deux voitures sur leur **coût total** (prix d'achat + énergie), année après année, en fonction des kilomètres parcourus.

👉 **Démo en ligne :** [https://k-ami-la.github.io/Cost_Car/)

![Capture d'écran](capture.png)

## Fonctionnalités

- Choix du modèle dans une liste (consommation remplie automatiquement)
- Essence, diesel ou électrique
- Calcul en direct du coût total et de l'écart entre les deux voitures
- Moment où les deux coûts s'égalisent
- Graphique de l'évolution du coût année par année
- Adapté au téléphone

## Technologies

- HTML, CSS, JavaScript (sans framework)
- [Chart.js](https://www.chartjs.org/) pour le graphique
- Hébergé sur GitHub Pages
